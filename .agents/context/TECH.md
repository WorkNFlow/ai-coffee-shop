# TECH — стек проекта «Бухта Coffee Roasters»

Версии проверены через Context7 MCP и npm registry (15 июля 2026).

| Технология/библиотека | Версия | Для чего используется в проекте |
|---|---|---|
| Astro | 7.0.9 | Генератор статического сайта: собирает одностраничную визитку в готовые HTML/CSS/JS-файлы для деплоя на Vercel и Timeweb |
| Tailwind CSS | 4.3.2 | Стилизация всех блоков страницы через утилитарные CSS-классы прямо в разметке, без отдельных CSS-файлов на каждый компонент |
| @tailwindcss/vite | 4.3.2 | Подключение Tailwind CSS к сборщику Astro через Vite |
| TypeScript | 7.0.2 | Типизация компонентов, данных меню/локаций и файлов переводов |
| @astrojs/vercel | 11.0.3 | Адаптер для деплоя на Vercel на этапе разработки и демо |
| Node.js | 20+ | Среда выполнения для локальной разработки и сборки проекта |

## Хостинг (не npm-пакеты)

| Сервис | Условия | Роль в проекте |
|---|---|---|
| Vercel (Hobby) | Бесплатно: SSL, ~100 ГБ трафика/мес, деплой через Git. Из России доступ нестабилен | Первичный хостинг для разработки и демо |
| Timeweb (Year+) | От ~180 ₽/мес, SSL бесплатно, 10 дней тестового периода, серверы в РФ | Финальный хостинг для российской аудитории; загрузка статических файлов после `npm run build` |
